# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python and Streamlit, as requested.

## Product Purpose
Automate research and draft preparation for B2B outreach with GPT-5 and Exa.

## Capabilities and Constraints
Company discovery; 2–3 supported contacts per company; 2–4 supported website/Reddit insights; individual email drafts. One to ten companies per run, four email styles, sidebar API keys, visible stages, downloads. Inferred emails must be labeled. No automatic email sending.

## Operating Context
A local Streamlit session with user-provided API credentials. The user approved following the guide as written. Publishing source to nexttokenlab on GitHub is requested.

## Product Principles
Evidence before personalization. Explicit uncertainty. Reviewable drafts. No committed secrets.
